# Интеграции на сервере AdCrew

Для общей базы и интеграций нужен один сервер AdCrew с Node.js 24+, HTTPS и постоянным диском для `KADR_DB_PATH`. Пользователи входят по общей ссылке. Для рабочей базы сначала подготовьте учётную запись руководителя, затем запустите сервер с `KADR_DEMO_MODE=0` и `KADR_SECURE_COOKIE=1`. GitHub Pages размещает браузерное демо с отдельной базой в каждом браузере.

Храните реквизиты в секретах хостинга или в локальном файле `.env.local`, который исключён из Git. Передайте значения серверному процессу и перезапустите его. Оставьте параметры сервиса пустыми, если его пока подключать не нужно. Статус «Параметры заданы» означает, что сервер распознал настройки. Он не подтверждает доступ к аккаунту или успешную доставку.

| Переменная | Значение |
| --- | --- |
| `KADR_PUBLIC_URL` | Адрес рабочей области по HTTPS, используемый в ссылках Telegram и Slack |
| `KADR_TELEGRAM_BOT_TOKEN` | Токен бота Telegram |
| `KADR_TELEGRAM_CHAT_ID` | ID чата или публичное имя канала, куда бот может публиковать |
| `KADR_SLACK_WEBHOOK_URL` | Входящий вебхук Slack для выбранного канала |
| `KADR_DRIVE_FOLDER_ID` | ID папки, куда сохраняются копии |
| `KADR_GOOGLE_CLIENT_ID` | ID клиента OAuth в проекте Google Cloud с включённым Drive API |
| `KADR_GOOGLE_CLIENT_SECRET` | Секрет того же клиента OAuth |
| `KADR_GOOGLE_REFRESH_TOKEN` | Refresh token, выданный при авторизации с offline access и правом записи в целевую папку |

- **Telegram.** Создайте бота и добавьте его в выбранный рабочий чат с правом отправки сообщений. AdCrew публикует номер задачи, событие и ссылку на карточку при сдаче, возврате на правки и приёмке. [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage)
- **Slack.** Установите Slack App в нужное рабочее пространство, включите Incoming Webhooks и выберите рабочий канал. Для него AdCrew публикует те же события и ссылки. [Документация Slack](https://docs.slack.dev/messaging/sending-messages-using-incoming-webhooks/)
- **Google Drive.** Включите Drive API, создайте клиент OAuth и получите refresh token с согласия аккаунта, которому разрешена запись в папку. Для области `drive.file` целевая папка должна быть предоставлена приложению. При приёмке AdCrew копирует файлы принятой версии. Копии наследуют права папки, поэтому выдайте доступ к ней только нужным участникам. [Google OAuth](https://developers.google.com/identity/protocols/oauth2/web-server#offline), [области доступа Drive](https://developers.google.com/workspace/drive/api/guides/api-specific-auth), [загрузка файлов](https://developers.google.com/workspace/drive/api/guides/manage-uploads)

Отправка начинается после записи действия в SQLite. Ошибка провайдера не отменяет действие и записывается в журнал сервера без токенов и содержимого файлов. Автоматических повторов и очереди доставки пока нет. Проверки используют имитацию ответов API. Настоящие аккаунты, каналы и папка ещё не проверены.
